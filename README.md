# Relicta Session v0.8.13 · SillyTavern 확장

《렐릭타 온라인》 카드 전용 확장입니다. 매 턴 현재 세션 기록, 장소별 인물 명부, 실제 등장인물 정보, 숨은 제단 대기열을 AI에게 넣어 줍니다. 응답 끝의 숨은 ROAI 기록을 받아 상태창에 표시합니다. 추가 모델 호출은 없습니다.

## 설치

실리태번의 확장 설치 메뉴에 이 저장소 주소를 넣습니다. 그다음 《렐릭타 온라인》 v0.8.13 카드를 가져옵니다. 렐릭타 카드가 아닌 채팅에서는 아무것도 하지 않으며, 채팅 기록에 데이터를 남기지도 않습니다.

## 파일

| 파일 | 역할 |
|---|---|
| `index.js` | 실리태번 연결, 설정 패널, 슬래시 명령 `/relicta` |
| `ai-judgement.mjs` | 요청 주입문 작성, ROAI 검사와 부분 반영, 이름 언급 감지 |
| `router.mjs` | 장소별 명부, 실제 등장인물 정보, 숨은 해금 조건 |
| `altar.mjs` | 숨은 제단 대기열, 행운 보정 6단계, 정사 예외 기록 |
| `session.mjs`, `engine.mjs` | 세션 정규화, 제작자 시험 명령 |
| `status-ui.mjs`, `style.css` | 읽기 전용 상태창 |
| `presentation.mjs`, `st-presentation.mjs` | 꿈터 표시, 대화 사본 정리 |
| `sealed.mjs`, `cast-data.sealed.json` | 봉인된 인물 데이터와 해제 |
| `rules.json`, `catalog.json` | 성장식 초안, 샘플 아이템·스킬 |

인물 데이터는 봉인 파일로 들어 있습니다. 고칠 때는 배포 패키지의 `source/cast-data.json`을 편집하고 `node tools/seal-cast.mjs`로 다시 봉인합니다.

## 제작자 명령

- `/relicta 상태`
- `/relicta 행운 1~6` — 플레이어 본인의 소환·룰렛 행운 보정
- `/relicta 연결 이름` · `/relicta 연결해제 이름` — 현실 신원 연결
- `/relicta 심층 이름` · `/relicta 심층해제 이름` — 심층 전체 참고
- `/relicta 로그아웃` · `/relicta 접속`
- `/relicta 사망` · `/relicta 부활 일반|다이아|골드`

설정 패널의 인물 목록은 이름 검색으로 찾을 수 있습니다.

## v0.8.8 변경 사항
- 판정 대기 정보를 메모리뿐 아니라 채팅 기록(입력 메시지)에도 남깁니다. 생성 도중 채팅이 다시 불러와져도 응답이 판정되지 않고 넘어가던 문제(「연결됨」인데 「아직 판정한 응답 없음」)를 막습니다.
- 같은 확장이 두 폴더에 설치되어 있으면 하나만 동작하고, 패널에 경고를 띄웁니다.
- 응답이 기록되지 않고 건너뛰어지면 패널에 「기록 건너뜀 · 이유」 줄이 뜹니다.
- 카드·정규식·로어북은 v0.8.7 그대로 사용합니다.

## v0.8.9 변경 사항
- 응답 기록을 본문 전체가 아니라 숨은 판정 주석(`<!--ROAI:…-->`) 기준으로도 알아봅니다. 다른 확장이나 기능이 판정 뒤에 본문 글자를 고쳐도 기록·상태가 풀리지 않습니다.
- 확장 패널에 「진단 정보」 칸을 추가했습니다. 모바일에서도 길게 눌러 복사할 수 있습니다. 채팅창에 `/relicta 진단`을 입력해도 같은 내용이 알림으로 뜹니다.

## v0.8.10 변경 사항
- **연결이 끊기던 근본 원인 수정.** 실리를 켜고 캐릭터를 고르기 전에 패널이 그려지면 오류가 났고, 그 오류 때문에 실리 이벤트 연결이 통째로 건너뛰어졌습니다. 그래서 판정 요청은 나가는데 응답 기록·상태창·채팅 전환 갱신이 모두 멈춰 있었습니다. 이제 이벤트를 먼저 연결하고, 패널 오류가 나도 기록은 계속됩니다.
- 이벤트 연결이 안 된 상태면 패널에 경고가 뜹니다.

## v0.8.11 변경 사항
- **다른 확장과의 충돌 완화.** 응답 뒤에 이미지 생성 태그 등을 덧붙이는 확장과 함께 써도 본문이 잘려 보이지 않습니다. 화면용 본문 사본을 꼭 필요할 때만 만들고, 본문이 바뀌면 다시 맞춥니다.
- 상태창을 본문 안이 아니라 메시지 블록 끝에 붙입니다. 본문을 다시 쓰는 확장과 서로 건드리지 않습니다.

## v0.8.12 변경 사항
- 이미지 자동 생성(Image Auto Generation · 오토픽) 확장과 함께 쓸 때를 위해, AI에게 이미지 태그(`<pic prompt="…">`)를 판정 주석 **뒤에**, 닫힌 형태로 쓰라고 알려줍니다. 렐릭타의 마지막 지시가 이미지 태그를 밀어내지 않습니다.

### 오토픽과 함께 쓰기
- 오토픽의 삽입 방식은 「인라인」·「태그 교체」 모두 사용할 수 있습니다. 이미지는 본문 아래, 상태창 위에 나옵니다.
- 이미지 태그가 쓰다가 끊기면 실리의 **응답 길이(Max Response Length)**를 늘려 주세요. 렐릭타 판정 주석과 이미지 태그가 모두 응답 끝에 붙기 때문에 길이가 빠듯하면 맨 끝의 이미지 태그부터 잘립니다.
- 실리의 「불완전한 문장 다듬기(Trim Incomplete Sentences)」가 켜져 있으면 태그 끝이 잘릴 수 있습니다.

## v0.8.13 변경 사항
- 확장 패널의 버튼 글자가 한 글자씩 세로로 쌓이던 문제를 고쳤습니다(실리 기본 버튼 폭 규칙 보정).
