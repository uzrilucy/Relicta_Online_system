# Relicta Session v0.5

렐릭타 온라인 전용 SillyTavern 확장입니다. 지역별 명부·실제 등장인물 프로필, 채팅별 진행 기록, 일반 수치 판정과 상태창을 관리합니다. v0.5는 시스템 출력 규칙과 월드인포 기반 꿈터 토글을 지원합니다.

## 설치

SillyTavern의 확장 → 확장 설치에서 **이 저장소 주소**를 붙여넣고 설치한 뒤 새로고침하세요. 이어서 렐릭타 v0.5 카드 PNG 또는 JSON 하나를 가져오고 내장 정규식 사용을 허용합니다. Git 방식 설치에는 SillyTavern을 실행하는 서버의 Git이 필요합니다.

이미 설치했다면 확장 관리에서 업데이트하고 새로고침합니다. 이전 확장을 다른 폴더에 중복 설치하지 않습니다. 확장 파일만으로는 렐릭타 캐릭터 카드가 추가되지 않습니다.

## 꿈터 옵션

연결된 월드인포에서 `[USER-OPTION:DREAMTEO] 사용자 설정 · 꿈터 항상 켜기` 항목을 찾습니다. 기본값은 비활성화(끔)입니다. 파란 원 상시 전략은 그대로 두고 항목 활성 스위치로 켜거나 끕니다. 저장한 다음 새 응답부터 적용합니다. 같은 책을 연결한 채팅에 공통으로 적용됩니다.

ON: 본문 뒤에 익명 글 2개와 각 글의 댓글 1개. OFF: 게시판을 생략합니다. 과거 게시판은 다음 모델 입력에서 제외하며 저장 원본은 보존합니다. 비공개 대화·쪽지·현실 신원·숨겨진 설정·내부 확률은 게시판 소재로 쓰지 않습니다.

## 호환·기록

v0.4와 같은 `relicta_session_v04`/RO4 기록을 유지합니다. 다른 캐릭터에는 자동으로 켜지지 않습니다. 내장 정규식은 카드 범위에서만 사용합니다. 실제 거래·외부 로그인·별도 서버 서비스가 없는 로컬 시뮬레이션입니다.

일반 판정은 구현되어 있지만 성장식/세부 확률은 밸런스 초안입니다. 165명의 고유 능력과 나락 전용 기믹 전체를 자동 수치화한 엔진은 아닙니다. 연결 모델·실제 브라우저에서의 플레이 검증은 별도 단계입니다.

## 저장소 관리

이 README, manifest.json, index.js 및 모든 .mjs/.css/.json 파일이 **저장소 최상위**에 있어야 합니다. GitHub Pages 설정은 필요하지 않습니다. 설치 주소는 저장소 주소입니다. 카드·월드인포·규칙 설명·검사 결과는 전체 배포 패키지에서 제공합니다.
