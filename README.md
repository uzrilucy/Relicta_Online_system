# Relicta Session v0.6

렐릭타 온라인 전용 SillyTavern 확장입니다. 조건부 명부, 채팅별 기록, 판정과 상태창을 관리합니다.

확장 설치에서 이 저장소 주소를 붙여넣고 설치/업데이트한 뒤 새로고침하세요. v0.6 카드 PNG 또는 JSON 하나를 가져오고 내장 정규식 사용을 허용합니다. 카드·연결 월드인포·확장을 함께 v0.6으로 갱신하세요. Git 방식 설치에는 SillyTavern 서버의 Git이 필요합니다.

꿈터는 연결된 월드인포의 `[USER-OPTION:DREAMTEO] 사용자 설정 · 꿈터 항상 켜기`에서 선택합니다. 기본 OFF. 파란 원 상시 전략은 유지하고 항목 활성 스위치를 조작합니다. ON이면 본문 다음 4~6글, 각 본문 2~5줄/댓글 3~5개를 붙입니다. 한탄은 약5% 권장 비중, 한 화면 최대1개이며 대부분에는 없습니다. 지난 게시판은 다음 모델 입력에서 생략하고 원본을 보존합니다.

v0.6 상태창은 구작 Somnium Record를 따른 정보 중심 기록입니다. 전투·이동 조작과 상시 행동 버튼은 표시하지 않습니다. 기존 수치 기록과 명시적 채팅 명령/API는 유지합니다. 다른 캐릭터에는 자동으로 켜지지 않습니다.

README, manifest.json, index.js 및 모든 mjs/css/json 파일이 저장소 최상위에 있어야 합니다. 카드·설명·검사 결과는 전체 패키지에서 제공합니다. 실제 외부 결제/로그인은 없으며 수치 산식은 밸런스 초안입니다. 연결 모델·브라우저 종합 검증은 별도입니다.
